================================================================================
VKclips
================================================================================

Бот собирает YouTube Shorts по хэштегам, уникализирует через FFmpeg
и постит в сообщества VK по расписанию.

--------------------------------------------------------------------------------
ЧТО УМЕЕТ
--------------------------------------------------------------------------------

- Собирает Shorts по тегам из hash.txt и фильтрует по просмотрам,
  лайкам, длительности.
- Уникализирует видео через FFmpeg (кроп, скорость, цвет, вотермарка,
  метаданные).
- Постит в VK с лимитами: на группу, на аккаунт, кулдаун,
  глобальный интервал.
- Сам обновляет VK-токен раз в 22 часа.
- Чистит старые посты и собирает статистику раз в сутки.
- Шлёт алерты в VK админу.

--------------------------------------------------------------------------------
ТРЕБОВАНИЯ
--------------------------------------------------------------------------------

- Python 3.10+
- FFmpeg (в PATH)
- Chrome/Chromium (для автообновления токена)
- VK-аккаунт + Standalone-приложение VK
- YouTube Data API v3 ключ

--------------------------------------------------------------------------------
УСТАНОВКА
--------------------------------------------------------------------------------

    git clone <URL>
    cd VKclips2

    python -m venv .venv
    .venv\Scripts\activate          # Windows
    source .venv/bin/activate       # Linux/macOS

    pip install -r requirements.txt

--------------------------------------------------------------------------------
НАСТРОЙКА
--------------------------------------------------------------------------------

1. Скопируй .env.example -> .env и заполни:

    VK_ACCESS_TOKEN=
    VK_USER_TOKEN=
    VK_GROUP_TOKEN=
    VK_GROUP_ID=
    VK_ADMIN_ID=
    VK_ALERT_PEER_ID=
    YT_API_KEY=
    VK_CLIENT_ID=
    VK_CLIENT_SECRET=

2. Хэштеги — в hash.txt, по одному на строку, без #.

3. Настройки (лимиты, интервалы, фильтры) — в config/config.py.

4. Добавь сообщество через add_group.py (имя, group_id, daily_limit):

    python add_group.py

5. Опционально: watermark.mov для вотермарки, music/*.mp3 для музыки.

--------------------------------------------------------------------------------
ЗАПУСК
--------------------------------------------------------------------------------

Первый раз — получить токен вручную:

    python scripts/get_vk_token.py

Дальше — просто:

    python run_all.py

Остановка — Ctrl+C.

--------------------------------------------------------------------------------
СТРУКТУРА
--------------------------------------------------------------------------------

    VKclips2/
    |-- run_all.py              # оркестратор
    |-- add_group.py            # добавление группы
    |-- patch.py                # патчер настроек
    |-- hash.txt                # хэштеги
    |-- config/config.py        # все константы
    |-- core/                   # логика (db, youtube, processor,
    |                           # vk_auth, notifier, ...)
    |-- scripts/                # populator, loader, vk_listener,
    |                           # vk_cleaner, stats_collector
    |-- data/                   # БД и служебные файлы (не коммитить)

--------------------------------------------------------------------------------
КАК РАБОТАЕТ
--------------------------------------------------------------------------------

1. populator — собирает ID Shorts с YouTube, фильтрует, кладёт в очередь.

2. loader — берёт из очереди, скачивает, уникализирует, постит в VK.

3. vk_listener — слушает события VK.

4. vk_cleaner + stats_collector — раз в сутки чистят и собирают
   статистику.

5. run_all.py — следит за процессами, перезапускает упавшие,
   обновляет токен.

--------------------------------------------------------------------------------
ЛОГИ
--------------------------------------------------------------------------------

- logs/orchestrator.log — оркестратор
- logs/<process>.log    — каждый процесс
- Ротация раз в сутки, хранится 14 файлов
- Алерты уходят в VK через core/notifier.py

--------------------------------------------------------------------------------
ЧАСТЫЕ ПРОБЛЕМЫ
--------------------------------------------------------------------------------

"Не удалось подготовить VK-токен"
    -> запусти python scripts/get_vk_token.py в терминале.

FFmpeg не найден
    -> установи и добавь bin в PATH, либо поправь FFMPEG_PATH
       в core/processor.py.

Все видео отфильтровываются
    -> ослабь MIN_VIEWS, MIN_LIKES_RATIO в config/config.py.

Посты не уходят
    -> проверь daily_limit группы и лимит аккаунта
       в core/account_guard.py.
